# 문서24 재발송기

문서24에서 **마지막 전송문서를 재작성**하여 여러 수신기관에 순차적으로 보내는 macOS용 업무 자동화 MVP입니다.

## 현재 기능

- 문서24 법인 계정 아이디/비밀번호 입력
- 마지막 전송문서 제목 확인
- 수신기관 직접 입력
- CSV/XLSX 수신기관 목록 불러오기
- 마지막 전송문서 재작성 반복
- 수신기관 검색 및 선택
- 실제 발송 전 테스트 모드
- 검색/처리 실패 기관을 `~/Downloads/문서24_실패목록_*.csv`로 저장
- 실제 발송 전 최종 확인창

## 중요한 안전 규칙

- 로그인 아이디/비밀번호를 소스코드나 파일에 저장하지 않습니다.
- 반드시 `마지막 전송문서 확인` 후 발송을 시작합니다.
- 기본 상태는 테스트 모드입니다. `실제 발송`을 직접 체크해야 최종 보내기 버튼을 누릅니다.
- 문서24 화면 구조가 변경되면 Playwright 선택자를 수정해야 할 수 있습니다.

## 개발 환경에서 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Google Chrome이 `/Applications/Google Chrome.app`에 설치되어 있어야 합니다.

## macOS 앱 빌드

GitHub Actions의 `Build macOS App` 워크플로가 `Doc24Sender-macOS.zip`을 생성합니다.
압축을 풀면 `Doc24Sender.app`을 실행할 수 있습니다.

서명되지 않은 개발용 앱이므로 macOS가 첫 실행을 막는 경우 Finder에서 앱을 우클릭한 뒤 `열기`를 선택해야 할 수 있습니다.

## 현재 MVP 범위

현재는 사용 빈도가 가장 높은 **마지막 전송문서 재발송** 흐름만 구현합니다. 새 공문 작성, 첨부파일 신규 업로드, 예약 발송 등의 기능은 아직 포함하지 않습니다.
